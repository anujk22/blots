# Blots artwork

Created with the built-in GPT Images tool for this app. The supplied assets are local files; viewing Blots never calls an image service.

- `public/mascot.png`: transparent cobalt satin ink-blot mascot with eight rounded lobes, tiny warm-white eyes and a relaxed smile. Quiet, polished 3D material, readable on OLED black. Also exported into the Mac icon sizes and used in the Linux home page.
- `computer/wallpaper.png`: OLED-black 16:10 wallpaper, restrained cobalt glass ribbons along the bottom-left and top-right edges, an empty dark center for the clock and search.

Generation prompts requested no text, no logos, and no surrounding interface. App artwork was generated directly, then copied into the repository; Mac icon variants are standard size exports.
