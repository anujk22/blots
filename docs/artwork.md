# Blots artwork

Created with the built-in GPT Images tool for this app. The supplied assets are local files; viewing Blots never calls an image service.

- `public/mascot.png`: transparent cobalt satin ink-blot mascot with eight rounded lobes, tiny warm-white eyes and a relaxed smile. Quiet, polished 3D material, readable on OLED black. Exported into the Mac icon sizes and used for Blot’s small profile image. Teammates use simple initials with their chosen colors.

The earlier glass wallpaper and desktop mascot were removed after visual review. The Linux start page now uses a flat blue-gray surface and system Adwaita app icons.

Generation prompts requested no text, no logos, and no surrounding interface. App artwork was generated directly, then copied into the repository; Mac icon variants are standard size exports.
